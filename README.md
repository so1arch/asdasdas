# Medieval Combat — Fabric 1.20.1

## Сборка .jar
1. Установите JDK 17 и Gradle 8.6+ (или скопируйте `gradlew`, `gradlew.bat` и `gradle/wrapper/gradle-wrapper.jar` из официального шаблона fabric-example-mod).
2. В папке проекта выполните:
   - `gradle wrapper --gradle-version 8.6` (если нет gradlew)
   - `./gradlew build` (Windows: `gradlew.bat build`)
3. Готовый мод: `build/libs/medievalcombat-1.0.0.jar` (файл `-sources.jar` не нужен).
4. Положите его в `mods/` вместе с Fabric API для 1.20.1 (0.92.2 и новее).

## Управление боем
- Зона атаки/защиты выбирается движением мыши: рывок влево/вправо/вверх/вниз. Мышь неподвижна ~0.7 с — центр (колющий удар). Справа от прицела подсвечивается текущая зона.
- ЛКМ — удар в текущей зоне. ПКМ (удерживать) — защита.
- Защита в той же зоне, что и удар врага: блок почти без урона. Если поднять защиту прямо перед ударом (первые 0.6 с) в совпадающей зоне — парирование: враг оглушён, у вас окно "мастер-удара" (x2.2 урона, игнорирует блок).
- Полоса выносливости над здоровьем. Удары и блоки её тратят; тяжёлая броня замедляет восстановление. При нуле выносливости защита ломается.
- Рубящие удары хуже пробивают латы, колющие (эсток, кинжал) — лучше.

## Ресурсы
`python3 tools/generate_assets.py` пересоздаёт все модели, текстуры, рецепты и переводы (нужен Pillow).
Если мечи в руке наклонены в другую сторону, поменяйте `TILT = -45` на `45` в этом скрипте и запустите его заново.
